## 1. Notes (padho · 20 min)

### Cloud Computing
- Internet pe IT resources (servers, storage, software) on demand.
- Pay-as-you-go, scalable, remote access.

**Service models:**
| Model | Meaning | Example idea |
|---|---|---|
| **IaaS** | Infrastructure as a Service | Virtual machines, storage |
| **PaaS** | Platform as a Service | Dev platform (runtime, DB tools) |
| **SaaS** | Software as a Service | Gmail, Office 365 style apps |

**Deployment:**
| Type | Meaning |
|---|---|
| **Public** | Shared, provider-owned cloud |
| **Private** | Single organization |
| **Hybrid** | Public + Private mix |
| **Community** | Shared by related orgs |

**Benefits:** cost save, scalability, backup, accessibility  
**Risks:** security, downtime, vendor lock-in, data privacy

### Virtualization (related)
- One physical machine → multiple virtual machines.
- Better resource use; cloud ka base technology.

### MIS (Management Information System)
- System that provides **information for managers** to decide.
- Collect → process → store → report data.
- Helps planning, control, decision-making.
- Levels: operational / tactical / strategic reports.
- Related: DSS (Decision Support), EIS (Executive Information).

### Quick bank IT terms
- **Core Banking** — centralized banking software
- **CRM** — Customer Relationship Management
- **ERP** — Enterprise Resource Planning
- **Data Warehouse** — large analytical data store
- **Backup / DR** — Disaster Recovery
