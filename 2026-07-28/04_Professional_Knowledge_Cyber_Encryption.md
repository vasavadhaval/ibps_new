## 1. Notes (padho · 20 min)

### CIA (revision)
- **Confidentiality** — authorized access only  
- **Integrity** — data not changed illegally  
- **Availability** — system up when needed  

### Encryption
| Type | Idea |
|---|---|
| **Symmetric** | Same key encrypt + decrypt (AES, DES) — fast |
| **Asymmetric** | Public + Private key pair (RSA) — secure key exchange |
| **Hashing** | One-way fingerprint (MD5, SHA) — integrity check, passwords |
| **Digital Signature** | Private key se sign, public key se verify — authenticity |
| **SSL/TLS / HTTPS** | Secure web traffic (port 443) |

**Remember:** Hashing ≠ Encryption (hash usually irreversible).

### More attacks / controls
| Term | Meaning |
|---|---|
| Phishing | Fake mail/link |
| Ransomware | Lock files for money |
| Spyware | Secretly monitors |
| Trojan | Malware disguised as useful |
| Brute force | Try many passwords |
| Social engineering | Trick humans |
| Firewall | Filter traffic |
| IDS/IPS | Detect/prevent intrusions |
| 2FA/MFA | Extra authentication factor |
| VPN | Secure tunnel |
| Patching | Fix vulnerabilities |

### Password hygiene (exam + real)
- Strong unique passwords, MFA on, OTP never share.
