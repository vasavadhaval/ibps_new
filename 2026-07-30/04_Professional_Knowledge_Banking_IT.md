## 1. Notes (padho · 20 min)

### Banking systems
| Term | Meaning |
|---|---|
| **CBS / Core Banking** | Centralized banking — any branch/channel access |
| **NEFT** | National Electronic Funds Transfer (batch) |
| **RTGS** | Real Time Gross Settlement (large value, real-time) |
| **IMPS** | Immediate Payment Service (instant 24×7) |
| **UPI** | Unified Payments Interface — mobile instant pay |
| **ATM** | Automated Teller Machine |
| **POS** | Point of Sale |
| **CTS** | Cheque Truncation System (image-based clearing) |
| **SWIFT** | International bank messaging |

### Security / compliance (bank IT)
| Term | Meaning |
|---|---|
| **KYC** | Know Your Customer |
| **AML** | Anti Money Laundering |
| **2FA / MFA** | Extra authentication |
| **OTP** | One Time Password — never share |
| **Encryption / HTTPS** | Protect data in transit |
| **Firewall / SOC** | Network defense / Security Operations Centre |

### IT in bank roles (exam flavour)
- Server, database, network, application support
- Backup, DR (Disaster Recovery), BCP (Business Continuity)
- Vendor management, patch management
- Digital channels: mobile banking, internet banking

### Quick compare
| NEFT | RTGS | IMPS/UPI |
|---|---|---|
| Batch | Real-time gross | Instant |
| Smaller/common | High value | 24×7 retail |
