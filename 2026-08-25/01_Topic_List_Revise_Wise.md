## 🇬🇧 2. English (25 Q · 25 marks · 20 min)

### ⭐ Aaj MUST

| Topic | Trap |
|---|---|
| Subject–verb (neither–nor → nearer noun) | Mock: friends → **are** |
| for / since (duration vs point) | lived **for** five years |
| Hardly / Scarcely … **when** | not *then* |
| Uncountable: scenery, furniture, information | not *sceneries* |
| suggest / avoid / enjoy + **-ing** | suggested **leaving** |
| Idioms: once in a blue moon = rarely | drop of a hat = immediately |
| Prevent + from + -ing; capable **of** | |
| junior / senior / prefer **to** (not than) | |
| Unless = if not (double negative mat) | |

### 🔹 Light

RC main idea + vocab from context · Error spotting rhythm

## 🔢 4. Quantitative Aptitude (25 Q · 25 marks · 20 min)

**Status:** Cut-off OK, lekin **9 skips** = biggest enemy.

### ⭐ Aaj MUST (attempt pehle, theory baad)

| Topic | Exam tip |
|---|---|
| Simplification / √ / BODMAS | Easy marks — pehle |
| Approximation | Round → calculate |
| Number series (× / + pattern) | 2 series try, 3rd skip OK |
| Age (ratio + after years) | Equation 1 line |
| SI (principal / amount / interest) | SI = PRT/100 |
| Profit % | (SP−CP)/CP × 100 |
| Average replace | Δ / n |
| Percentage find number | x% of N = given → N |
| DI (table): total, avg, lowest, % | Read labels carefully |

### Exam order (20 min Quant)
1. DI + Simpli + Approx (8–10 Q)  
2. Series + % + SI + P&L (5–6)  
3. Age / Quadratic only if clear  
4. Tough → **skip** (max 3 skips, not 9)

### ⛔ Aaj mat

Permutation–Combination deep, Probability advanced, Geometry theorems.
