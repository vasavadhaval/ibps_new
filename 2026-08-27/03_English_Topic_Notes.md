## Topic 1 — Subject–Verb Agreement

| Rule | Example |
|---|---|
| Singular subject → singular verb | The number of applicants **is**… |
| One of + plural → singular | One of my friends **is**… |
| Neither A nor B → **nearer** subject | Neither Ramesh nor his friends **are** |
| Either A or B → nearer | Either manager or clerks **are** |
| Collective (usually) | The team **is**… |

## Topic 2 — for / since / from

| Word | Use |
|---|---|
| **for** | Duration — for five years |
| **since** | Starting point — since 2019 |
| from | From Monday to Friday (range) |

## Topic 3 — Hardly / Scarcely / No sooner

| Pattern | Connector |
|---|---|
| Hardly / Scarcely … | **when** (not then) |
| No sooner … | **than** |

## Topic 4 — Uncountable nouns

Usually **no plural s**: scenery, furniture, information, advice, luggage, news  
→ The **scenery is** beautiful · The **furniture is** costly

## Topic 5 — Verb patterns

| Verb | Form |
|---|---|
| suggest / enjoy / avoid / mind / finish / insist on | **+ -ing** |
| prevent / stop | + object + **from** + -ing |
| capable | **of** + -ing |
| want / decide / hope | + **to** + V1 |

## Topic 6 — Fixed prepositions

| Wrong vibe | Correct |
|---|---|
| good in cricket | good **at** |
| junior than | junior **to** |
| congratulate for | congratulate **on** |
| interested on | interested **in** |
| despite of | **Despite** / In spite **of** |
| discuss about | **discuss** (no about) |
| order for coffee | **order** a coffee |
| return back | **return** |
| more taller | **taller** |

---

## Topic 7 — Unless / Articles / Improve

- Unless = if not → **Unless you work hard** (not “do not”)  
- An + vowel sound: **An** apple, **An** honest man  
- She **doesn't** (not don't)
