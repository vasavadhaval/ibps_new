## Topic 3 — Syllogism

| Pattern | Tip |
|---|---|
| All A are B + Some B are C | Some A are C? **Not definite** |
| All A are B + All B are C | All A are C? **Follows** |
| No A is B + All B are C | No A is C? **Not definite**; Some C not A often **follows** (via B) |

Venn socho; extreme “all reverse” usually false.
